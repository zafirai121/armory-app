# مستودع السرية

تطبيق ويب لإدارة مستودع السرية: الأسلحة والأعتدة والمنتسبين وما بذمة كل منتسب، مع سجل كامل لكل حركة وتقارير جاهزة للطباعة.
يعمل على الهاتف والحاسوب، ويمكن تثبيته على الشاشة الرئيسية ليعمل كتطبيق، ويستمر بالعمل بدون إنترنت.

## ماذا يفعل

- **الأسلحة**: كل سلاح يُسجَّل برقمه التسلسلي ونوعه وطرازه وعياره ومكان خزنه. حالاته: في المستودع، مسلّم، في الصيانة، عاطل، مفقود.
  - تسليم سلاح لمنتسب، وإرجاعه (سليم / يحتاج صيانة / عاطل / مفقود)، وتغيير حالته، وشطبه من القيود.
- **الأعتدة**: كل صنف بعياره ورقم وجبته ووحدة قياسه (طلقة، صندوق، قنبلة…) وحد أدنى للتنبيه.
  - استلام وارد، صرف لمنتسب، إرجاع، تسجيل استهلاك (رمي تدريبي، واجب)، إخراج (إتلاف أو تسليم لجهة أخرى)، وتسوية جرد بعد العدّ الفعلي.
  - الأرصدة تُحسب من سجل الحركات نفسه، فلا يمكن صرف أكثر من الموجود ولا إرجاع أكثر مما بذمة المنتسب.
- **المنتسبون**: الاسم والرتبة والرقم العسكري والفصيل والهاتف، وصفحة لكل منتسب تعرض ذمته وسجله.
- **السجل**: كل تسليم وإرجاع وصرف واستلام يُسجَّل تلقائياً بالتاريخ والوقت والملاحظات، مع بحث وتصفية بالتاريخ.
- **الرئيسية**: خلاصة الأسلحة حسب الحالة، أرصدة الأعتدة، تنبيهات الرصيد المنخفض والأسلحة المفقودة، وآخر الحركات.
- **الطباعة**: تقرير الجرد العام، سند ذمة لكل منتسب بتواقيع (المستلم، أمين المستودع، آمر السرية)، وسجل الحركات.
- **التصدير**: جداول الأسلحة والأعتدة والمنتسبين والسجل بصيغة CSV تُفتح في Excel مع العربية سليمة.
- **قفل التطبيق** برمز سري اختياري، يُطلب عند الفتح وبعد بقاء التطبيق في الخلفية أكثر من دقيقتين.

## أين تُحفظ البيانات

البيانات تُحفظ **في متصفح الجهاز نفسه فقط** (localStorage)، ولا تُرسَل إلى أي خادم. يترتب على ذلك:

- كل جهاز له بياناته الخاصة، ولا تتزامن الأجهزة تلقائياً.
- مسح بيانات المتصفح يمسح السجلات، لذلك **خذ نسخة احتياطية بانتظام** من: الإعدادات ← تنزيل نسخة احتياطية. يذكّرك التطبيق إذا مضى أكثر من 7 أيام بلا نسخة.
- النسخة الاحتياطية ملف JSON يحتوي كل السجلات؛ احفظه في مكان آمن، ويمكن استعادته على الجهاز نفسه أو جهاز آخر.
- قفل التطبيق يمنع من يمسك الجهاز من فتحه، لكنه **لا يشفّر** البيانات المحفوظة في المتصفح.

## التشغيل

يحتاج [Node.js](https://nodejs.org) الإصدار 20 أو أحدث.

```bash
npm install
npm run dev       # تشغيل للتطوير على http://localhost:5173
npm test          # اختبارات منطق المستودع (الأرصدة، الذمم، النسخ الاحتياطي)
npm run build     # بناء النسخة النهائية في مجلد dist
npm run preview   # معاينة النسخة النهائية
```

## النشر

مجلد `dist` بعد البناء موقع ثابت (ملفات HTML وCSS وJS فقط) يمكن رفعه على أي استضافة ثابتة، مثل GitHub Pages أو Netlify أو خادم داخلي في الوحدة.
التطبيق لا يحتوي أي بيانات، فكل جهاز يفتحه يبدأ فارغاً ويحفظ سجلاته عنده.

> ملاحظة: لا يعمل بفتح `dist/index.html` مباشرة من الملفات؛ يجب تقديمه عبر خادم (مثل `npm run preview`) أو استضافة.

بعد فتحه في متصفح الهاتف اختر «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق مستقل وبدون إنترنت.

## بنية المشروع

```
index.html          هيكل الصفحة: التنقل، الشريط العلوي، شاشة القفل
src/store.js        البيانات وقواعد العمل: الأسلحة والأعتدة والمنتسبون والسجل والأرصدة
src/views.js        الشاشات: الرئيسية، الأسلحة، الأعتدة، المنتسبون، السجل، الإعدادات
src/forms.js        نماذج الإدخال والحركات (تسليم، إرجاع، صرف، استلام…)
src/reports.js      الطباعة والتصدير والنسخ الاحتياطي
src/lock.js         قفل التطبيق بالرمز
src/ui.js           أدوات مشتركة: النوافذ، الحقول، البحث العربي، التنسيق
src/demo.js         بيانات نموذجية للتجربة
public/sw.js        العمل بدون إنترنت
tests/              اختبارات store.js
```
